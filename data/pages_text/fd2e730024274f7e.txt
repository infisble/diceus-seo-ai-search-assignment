INSIS Modernized Claims API development for Fadata Services provided Legacy app modernization Expertise used Cloud computing Industry Software product Project overview Over the past years, Fadata has been working on another step in the evolution of INSIS, an insurance process platform. They are turning INSIS into a cloud-native multi-tenant software solution. Built with open-source technologies, Java is the primary language on the backend, and Spring.io’s family of frameworks will be a centerpiece. Everything will run in containers on a Kubernetes cluster following the microservice pattern. The APIs are implemented in a contract-first approach, with OpenAPI as the contract specification and Spring.io’s family of frameworks as the implementation platform. So, our team participates in API development for the Modernized Claims module.
